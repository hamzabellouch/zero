# Zero (Portable)
أداة خفيفة ومحمولة بالكامل لإلغاء تثبيت البرامج ومسح بقاياها من الريجستري وملفات النظام على ويندوز، مكتوبة بلغة **++C**.

---

## 🚀 المواصفات التقنية
* **اللغة:** C++17 (Native Win32 API).
* **النوع:** محمول بالكامل (Portable) - ملف تنفيذي واحد ولا يحتاج إلى أي تثبيت.
* **الاعتماديات:** تم ربط الـ Runtime ذاتياً بشكل ثابت (`/MT`) بحيث لا يحتاج جهاز المستخدم إلى تثبيت أي مكاتب C++ Redistributable إضافية.
* **الحجم:** حوالي **400 كيلوبايت فقط**.
* **المسار:** `bin\Zero.exe`.

---

## 🛠️ المميزات الرئيسية
1. **اكتشاف البرامج المثبتة:**
   * قراءة برامج 64-بت و 32-بت من مسارات السجل:
     * `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`
     * `HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall`
     * `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall`
   * تصفية المكونات التلقائية والتحديثات الداخلية وعرض البرامج الفعلية فقط.

2. **شريط بحث سريع (Instant Search):**
   * فلترة فورية بمجرد كتابة اسم البرنامج أو اسم الشركة المطورة.

3. **إلغاء التثبيت العادي (Standard Uninstall):**
   * تشغيل أداة الحذف الرسمية التابعة للبرنامج مباشرة من السجل مع دعم أوامر MSI والأدوات المخصصة.

4. **فحص وحذف البقايا (Deep Clean / Leftover Scan):**
   * فحص شامل للملفات والمجلدات المتبقية في:
     * `%ProgramData%`
     * `%LocalAppData%`
     * `%AppData%` (Roaming)
     * `%LocalAppDataLow%`
     * `%ProgramFiles%` و `%ProgramFiles(x86)%`
     * مسار التثبيت الأصلي (Install Location).
   * فحص مفاتيح وقيم الريجستري في:
     * `HKEY_CURRENT_USER\Software`
     * `HKEY_LOCAL_MACHINE\Software` (64-بت و 32-بت)
     * مفتاح إلغاء التثبيت الخاص بالبرنامج.

5. **شاشة مراجعة البقايا قبل الحذف:**
   * نافذة تفاعلية تعرض قائمة البقايا (نوع العنصر، الحجم، المسار الكامل).
   * مربعات اختيار (Checkboxes) لكل عنصر لتمكينك من مراجعة وتحديد ما تريد حذفه بدقة.
   * أزرار (تحديد الكل / إلغاء التحديد).
   * تأكيد قبل الحذف النهائي لتجنب أي حذف غير مقصود.

6. **إزالة إجبارية من الريجستري (Force Remove):**
   * مخصصة للبرامج المعطوبة التي تظهر في قائمة ويندوز ولا تعمل أداة حذفها؛ يتم حذف مدخلاتها من السجل مباشرة.

7. **الأمان ونظام الحماية (Safety Whitelist):**
   * تضمين قائمة استثناء صارمة تمنع نهائياً مسح أو لمس أي مجلدات أو مفاتيح تابعة لنظام ويندوز أو مايكروسوفت أو ملفات النظام الأساسية.

## 📂 هيكلية المشروع
```text
Zero/
├── bin/
│   └── Zero.exe              <-- الملف التنفيذي المحمول الجاهز للتشغيل
├── src/
│   ├── main.cpp              <-- النافذة الرئيسية، شريط البحث، شريط الحالة، القوائم
│   ├── app_manager.h/.cpp    <-- قراءة البرامج المثبتة وتشغيل أدوات الحذف
│   ├── cleaner.h/.cpp        <-- محرك البحث عن بقايا الملفات ومفاتيح السجل
│   ├── ui_leftovers_dlg.h/.cpp <-- نافذة معاينة واختيار وحذف البقايا
│   ├── resource.h            <-- معرّفات الموارد
│   ├── app.rc                <-- ملف الموارد
│   └── app.manifest          <-- ملف الصلاحيات (Admin) وثيمات ويندوز والـ DPI
├── build/                    <-- ملفات التجميع المؤقتة (.obj, .res)
├── build.bat                 <-- سكربت التجميع التلقائي عبر MSVC 2022
└── README.md
```
